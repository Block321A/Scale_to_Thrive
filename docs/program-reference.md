# Scale to Thrive: Program Reference

Source: two proposal PDFs (IT Skills Program and Advanced Excel Program). Both are 12-week hybrid training programs for freshers, recent graduates and training partners.

**Delivery team (both programs):**
- Dr. Arjun U: HOD of CE, Principal VGST Project Handler, PES ITM and PES Center of Excellence
- Prajwal A: VGST Project Assistant, SDE Research Analyst, PES Center of Excellence

**Common themes:** hands-on labs, portfolio projects, weekly assessments, career prep (resume, mock interviews). The proposals explicitly say they do **not guarantee placement**. Target roles are "entry-level targets" only.

## Program A: Job-Oriented IT Skills Development

Tagline: *Master the skills. Build your future.* Flow: Learn → Practise → Build → Demonstrate.

| Item | Detail |
|---|---|
| Duration | 12 weeks |
| Hours | 96 guided (8/week) |
| Delivery | 2 online sessions × 2h (concepts; live demos and practice) + 1 offline lab × 4h (hands-on, troubleshooting, mini-projects) |
| Audience | Freshers and recent grads (B.E./B.Tech, BCA, MCA, B.Sc. CS, diploma); basic computer literacy |

### Career pathways
1. **Linux Administration**: Linux Administrator-Trainee, Linux Support Engineer L1, Junior Linux Admin. Skills: commands, users, permissions, services, storage, networking, logs, Bash.
2. **Python Automation**: Python Automation Engineer-Trainee, Junior Automation Engineer, Python Scripting Engineer. Skills: Python, Shell, file handling, CSV/JSON, logging, REST API, AWS S3.
3. **Python Development**: Junior Python Developer, Python Developer-Trainee, Junior Python Programmer. Skills: Python, OOP, data structures, SQL/PostgreSQL, REST, Git, testing.

### Technologies
Linux, Shell scripting, Python, REST API (Postman, Requests), PostgreSQL, Git/GitHub, AWS S3 (AWS CLI, Boto3, IAM basics), AI productivity tools.

### Curriculum
| Wk | Module | Key areas |
|---|---|---|
| 1 | Linux Fundamentals | Distros, lab setup, terminal, commands, file-system navigation |
| 2 | Linux Administration | Users, groups, passwords, sudo, permissions, ownership, package management |
| 3 | Advanced Linux Admin | Processes, services, systemd, SSH, networking, storage, logs |
| 4 | Shell Scripting | Variables, I/O, conditions, loops, functions |
| 5 | Shell Automation | grep, awk, sed, find, cron, backups, monitoring |
| 6 | Python Fundamentals | Types, operators, conditions, loops, functions, collections |
| 7 | Intermediate Python | OOP, modules, exceptions, files, CSV/JSON, Git basics |
| 8 | Python Automation | os, pathlib, shutil, subprocess, regex, logging |
| 9 | PostgreSQL & REST API | SQL, CRUD, joins, HTTP methods, status codes, JSON, Postman, Requests |
| 10 | Python Integration & Testing | DB connectivity, API integration, error handling, testing |
| 11 | AWS S3 & Integration Projects | S3, IAM, AWS CLI, Boto3, integrated project |
| 12 | AI for IT Professionals | AI-assisted Linux/Shell/Python, debugging, test generation, docs, safe validation |

### Projects
1. **Linux Server Monitoring**: CPU/memory/disk checks, process and log inspection, health report (Linux, Bash, Python).
2. **Python Automation Toolkit**: file organisation, CSV/JSON processing, API extraction, logging, optional S3 transfer.
3. **Employee Data Application**: Python + PostgreSQL CRUD, validation, error handling, REST practice.

Expectations: explain the problem, approach, code and outcome; keep code in GitHub; test normal and error cases; review AI-generated code before use.

### Responsible AI rules
Never share passwords, keys, tokens or confidential info with public AI tools. Review commands before running, especially delete, overwrite or permission changes. Test in a controlled environment. Students stay accountable for what they submit.

### Assessment
| Area | Weight |
|---|---|
| Technical quizzes | 10% |
| Weekly hands-on assignments | 20% |
| Module practical assessments | 20% |
| Project implementation and demo | 30% |
| Technical interview and project explanation | 20% |

## Program B: Advanced Excel & Corporate Readiness

Tagline: *Turn spreadsheet skills into career opportunities.* Flow: Understand → Practise → Analyse → Present.

| Item | Detail |
|---|---|
| Duration | 12 weeks |
| Hours | 60 guided (5/week) |
| Delivery | 1h hybrid communication + 1h online Excel concepts + 3h offline Excel lab |
| Audience | Freshers, grads, final-year students (B.Com, BBA, BCA, B.Sc., B.E./B.Tech, BA, diploma); no prior advanced Excel needed |
| Focus | Advanced Excel, MIS reporting, data analysis, dashboards, Power Query, intro VBA |

### Career pathways
1. **MIS & Reporting**: MIS Executive, MIS Analyst-Junior, Reporting Analyst-Trainee, Reporting Executive.
2. **Data & Business Analysis**: Data Analyst-Trainee, Business Analyst-Trainee, Operations Analyst-Junior, Data Management Executive.
3. **Corporate Operations**: Operations, HR Operations, Finance/Accounts, Sales Reporting, Inventory, Payroll-Junior executives.

Caveat in the proposal: Data and Business Analyst roles often also need SQL, Power BI, statistics or domain knowledge. These are offered as possible **follow-on modules** if the program expands.

### Curriculum
| Wk | Module | Communication focus (1h weekly) |
|---|---|---|
| 1 | Excel Foundations | Self-introduction, confidence |
| 2 | Data Entry & Cleaning | Spoken English fundamentals |
| 3 | Formula Fundamentals (IF, IFS, AND, OR, references, errors) | Professional conversations |
| 4 | Conditional & Summary Formulas (SUMIFS, COUNTIFS, AVERAGEIFS, SUBTOTAL) | Email writing and etiquette |
| 5 | Lookup Functions (VLOOKUP, HLOOKUP, XLOOKUP, INDEX/MATCH) | Explaining data and reports |
| 6 | Text, Date & Logical Functions | Presentation skills |
| 7 | Data Validation & Conditional Formatting | Meetings and active listening |
| 8 | PivotTables & PivotCharts | Group discussions |
| 9 | Dashboard Development | Interview preparation |
| 10 | Power Query | Resume and project explanation |
| 11 | Macros & VBA Introduction | Professional speaking, mock interview |
| 12 | Integrated Projects & Assessment | Final presentation and feedback |

Suggested 3-hour offline class: 60 min teaching, 30 min live demo, 75 min hands-on lab, 15 min review and assignment.

### Lab projects
1. **MIS Reporting Dashboard**: KPIs, PivotTables, charts, slicers.
2. **Sales Analysis & Target Tracker**: target vs actual, region/product summaries, trends.
3. **HR Attendance & Payroll Tracker**: date calculations, leave summaries, lookups, payroll support.
4. **Inventory & Purchase Report**: stock tracker, reorder indicators, purchase summaries.
5. **Power Query Data Consolidation**: merge monthly files, clean, refresh.

Outcomes: practical workbooks, at least one dashboard and one cleaning/consolidation project, a portfolio for interviews, better confidence explaining reports.

### Assessment
| Area | Weight |
|---|---|
| Concept checks and weekly quizzes | 10% |
| Weekly Excel exercises | 20% |
| Module practical assessments | 20% |
| Project implementation and demo | 30% |
| Communication, presentation, project explanation | 20% |

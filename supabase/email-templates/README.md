# Supabase email templates

Paste each file into Supabase: Authentication -> Emails -> (template). Set the subject too.

| Supabase template | Subject | File |
|---|---|---|
| Invite user | You are invited to Scale to Thrive | `invite.html` |
| Reset password | Reset your Scale to Thrive password | `recovery.html` |
| Confirm sign up | Confirm your email for Scale to Thrive | `confirmation.html` |
| Magic link | Your Scale to Thrive sign-in link | `magic-link.html` |
| Change email address | Confirm your new email address | `email-change.html` |
| Reauthentication | Your Scale to Thrive verification code | `reauthentication.html` |
